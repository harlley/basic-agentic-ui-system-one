# Basic Agentic UI — System One

Chat to change the square's color with DiffusionGemma structured decisions.

Uses the [free public endpoint](https://huggingface.co/spaces/victor/DiffusionGemma-free-endpoint). Messages and the current color are sent to that service. Manual controls work independently of it.

[Source code](https://github.com/harlley/basic-agentic-ui-system-one)
